# حضور مدارس الأحد

سيستم بسيط لمتابعة حضور المخدومين والخدام — بحث بالاسم وعلامة ✅ قصاد كل خانة.

## اللي بيتسجّل

**المخدومين:** القداس • التناول • الخدمة • التسبحة

**الخدام:** التحضير • الافتقاد • القداس • التناول • اجتماع الخدام • اجتماع الأسرة • الخدمة

فيه كمان علامة **"ده القداس الشهري"** بتتحط على اليوم كله، فتقدر تفرّق في التقارير بين القداس العادي والشهري.

## الصفحات

| الصفحة | الوصف |
|---|---|
| `/` | الرئيسية |
| `/attendance/students` | تسجيل حضور المخدومين |
| `/attendance/servants` | تسجيل حضور الخدام |
| `/students` | بيانات كل المخدومين (بحث بالاسم أو التليفون) |
| `/students/new` | تسجيل مخدوم جديد |
| `/absent` | غياب اليوم |
| `/students/[id]` | ملف المخدوم: بياناته + سجل حضوره + نِسَبه |
| `/reports` | ملخص آخر ١٥ يوم |

## البيانات

- فصل واحد للخدمة كلها
- ٢٢ مخدوم و٣٢ خادم متسجّلين من ملف الإكسل
- تقدر تضيف مخدوم جديد من صفحة `/students/new`، وبيظهر في كشف الحضور على طول

## قاعدة البيانات

ملفات `supabase/migrations` بتتطبّق بالترتيب على مشروع Supabase.

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # وحط القيم
npm run dev
```

## متغيّرات البيئة

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

## الأمان

- الدخول بحساب Supabase Auth (إيميل + كلمة سر).
- كل الجداول عليها RLS، والصلاحيات للمستخدم المسجّل دخوله بس — يعني مفيش حد يقدر يوصل لبيانات الأولاد من غير تسجيل دخول.

## التقنيات

Next.js 15 (App Router) • React 19 • Tailwind CSS 4 • Supabase (Postgres + Auth)
